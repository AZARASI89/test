# 实用命令生成器

一个纯前端的命令生成工具，通过浏览器即可快速拼装常用的 Shell 命令。

## 功能

- 统计指定文件夹中符合条件的文件数量
- 在目录树中查找匹配名称的文件
- 按内容检索文件并支持忽略大小写
- 支持针对多个文件或整个目录批量替换文本，可选正则表达式和大小写敏感

## 使用方式

1. 克隆仓库后直接双击 `web/index.html`，或通过任意静态服务器（如 `python -m http.server`）打开。
2. 在页面中填写需要的参数，点击“生成命令”。
3. 点击“复制”按钮即可将命令复制到剪贴板，在终端中执行。

## 开发说明

- 全部逻辑使用原生 HTML、CSS、JavaScript 实现，无需额外依赖或构建步骤。
- 样式采用响应式设计，桌面端和移动端都能良好展示。
- 如需扩展新的命令模板，可以在 `web/app.js` 中添加相应的表单处理函数。
