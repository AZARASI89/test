# 实用命令生成器

一个纯前端的命令生成工具，通过浏览器即可快速拼装常用的 Shell 命令。

## 功能

- 统计指定文件夹中符合条件的文件数量，可一次输入多种文件名模式
- 在目录树中查找匹配名称的文件，支持 *.conf、*.sql 等多后缀组合
- 按内容检索文件：支持多文件名匹配、多条包含/排除条件、可选显示路径/行号并可将结果导出为时间戳命名的 txt 文件
- 支持针对多个文件或整个目录批量替换文本，可选正则表达式、大小写敏感，并可生成/还原 `.bak` 备份
- 日志与输出分析：tail 实时追踪、awk/cut/jq 提取、热点统计与区段导出，并可一键保存结果
- 系统与资源排查：生成 df/du、进程排序、端口监听、系统快照等常用命令
- 批量文件处理：find 条件执行、批量重命名/移动、tar/zip/rsync 归档、diff 生成补丁
- 安全与权限：批量 chmod/chown 预览执行、SSH 登录模板、hash 校验、ACL 查看/设置/克隆
- HDFS 工具箱：浏览统计、内容查看、上传下载、append/setrep/chmod、目录管理以及 dfsadmin/fsck/test 诊断
- 页面提供日语（默认）、英语与简体中文三种界面语言，可通过右上角的下拉框即时切换

## 使用方式

1. 克隆仓库后直接双击 `web/index.html`，或通过任意静态服务器（如 `python -m http.server`）打开。
2. 页面右上角的下拉框可切换界面语言，默认以日语展示。
3. 页面默认收起所有功能面板，展开需要的功能后填写参数并点击“生成命令”。
4. 点击“复制”按钮即可将命令复制到剪贴板，在终端中执行。
